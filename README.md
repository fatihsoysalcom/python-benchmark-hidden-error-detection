# Python Benchmark Hidden Error Detection

This Python script demonstrates how benchmarks can reveal hidden bugs. It compares the execution time of a correct data processing function against one with a subtle bug that causes it to skip operations. A significant performance difference signals a potential issue that warrants further investigation.

## Language

`python`

## How to Run

Run this script using Python: `python benchmark_detector.py`
